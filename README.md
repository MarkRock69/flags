# Flags
This repository contains flags I have gathered over time or designed myself. Some of those were designed as early as 2022, and none of those should be taken to represent any political view I hold. In fact, I am opposed to the ideas implied by some of these flags, but I still want to keep them for documentation purposes.

No AI whatsoever was used to create, or assist with creating, any flag in this repository.

[not-mine](/not-mine/) contains necessary [attributions](/not-mine/!attributions.md) for all the flags it contains.
